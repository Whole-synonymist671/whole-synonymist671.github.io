## ⚡ Using the application

Once you install the software, you can begin tracking your video files. Open the app from your desktop shortcut. The main window shows a clean workspace. Use the Add Video button to select a file from your machine. The app scans the video and generates a list of timestamps.

These timestamps act as markers. You can label these markers to explain what happens at specific points in the video. The software keeps this log in a ledger format. You can export this ledger into common industry formats. Use EDL for editing suites, or SRT if you need captions. The app supports files like FCPXML or OTIO, which makes handoff to editors easy.

## 🔍 Visual verification features

Check your work through the lazy verification tool. This feature displays a small thumbnail gallery of your video based on the timestamps you set. You can scroll through these thumbnails to ensure your code instructions match the visual content. If something looks wrong, click the thumbnail to jump to that moment in the original video. You can edit the timestamp or the description right there. 

## 🏗️ Managing your workflow

The app handles the technical heavy lifting so you save time. It tracks every change you make during the review process. This history helps if you need to revert to a previous state. If you work in a team, you can share the ledger file with others. They can open the file in their own copy of the app to see the same markers and descriptions. This creates a shared source of truth for your video projects.

## 🔧 Frequently asked questions

Do I need other software to run this?
No, the app comes with everything you need to function. You do not need to install extra code libraries or runtime environments.

Can I move the ledger files between computers?
Yes, simply save your ledger file and move it to another machine that has the app installed. Open the file via the File menu to access your data.

Does the software modify my original video files?
No, the app reads your video files but never changes them. It only creates a separate small ledger file to store your notes and timestamps.

What happens if I update the app?
Newer versions of the app keep your data safe. Your existing ledger files will work in newer versions without extra steps.

## 🛡️ Privacy and data

Your data stays on your local machine. The software does not send your videos or your ledger data to the cloud. You control where your files live. We provide a tool that runs fully offline to ensure your project remains your own. If you have concerns about data security, you can block the app from accessing the internet through your firewall. It works just as well without a web connection.
